## ✦ Preview

A colorful **Bento-style mathematics learning interface** built to make **Komposisi Fungsi & Fungsi Invers** easier to understand through visual explanations and interactive experiments.

Instead of only reading formulas, you can **explore the function, test it, and see why the steps work.**

> `Learn → Explore → Practice → Understand`

---

## ◈ Features

* ⟡ **Bento UI** with responsive layouts
* ∫ **KaTeX** mathematical rendering
* ⚙ **Function Machine**
* ∘ **Composition Explorer**
* ↻ **Inverse Function Stepper**
* ◌ **Domain Radar**
* ? **Why Ladder**
* ▣ **Interactive Flashcards**
* ⌕ **Search & Focus Mode**
* ✎ **Personal Notes**
* ◈ **Quizzes & True/False Drills**
